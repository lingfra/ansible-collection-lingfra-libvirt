# Ansible Collection - lingfra.libvirt

Install, configure and manage libvirt.

## Included Content

### Roles

- [libvirt_guests](./roles/libvirt_guests/README.md): Configures libvirt-guests.service.
- [libvirt_install](./roles/libvirt_install/README.md): Installs libvirt for KVM/QEMU.
- [libvirt_manage](./roles/libvirt_manage/README.md): Manages virtual machines (domains) in libvirt.

### Playbooks

- [libvirt_setup](./playbooks/libvirt_setup.yaml): Installs and configures libvirt on the target hosts by including the roles libvirt_install and libvirt_guests.

## Installation

This collection is published to [Ansible Galaxy](https://galaxy.ansible.com). It
can be installed using the Ansible Galaxy CLI:

```bash
ansible-galaxy collection install lingfra.libvirt
```

It is also possible to specify this collection in the `requirements.yaml` (or
`requirements.yml`) file:

```yaml
---
collections:
  - name: lingfra.libvirt
    version: "v1.0.0"   # optionally specify version
```

And use the Ansible Galaxy CLI to install the definitions from the requirements
file:

```bash
ansible-galaxy install -r requirements.yaml
```

Alternatively, the collection can be obtained from the Git repository. This may
be desirable to get the latest development version. The following
`requirements.yaml` entry, can be used to download directly from Git:

```yaml
---
collections:
  - name: https://github.com/lingfra/ansible-collection-lingfra-libvirt
    version: main
    type: git
```

For more information, see the [Installing
collections](https://docs.ansible.com/ansible/latest/collections_guide/collections_installing.html)
section of the Ansible documentation.

## Usage

For installing [libvirt](https://libvirt.org/) and configuring the
`libvirt-guests.service` the existing playbook can be imported:

```yaml
- name: Import playbook lingfra.libvirt.libvirt_setup
  ansible.builtin.import_playbook: lingfra.libvirt.libvirt_setup
  vars:
    target: hypervisor.example.com    # replace with your hostname
```

See the documentations of [libvirt_install](./roles/libvirt_install/README.md)
and [libvirt_guests](./roles/libvirt_guests/README.md) for available variables.

To create virtual machines in [libvirt](https://libvirt.org/) refer to the
documentation of [libvirt_manage](./roles/libvirt_manage/README.md).
